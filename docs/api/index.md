# API reference

ddma has two interfaces on one C++ core, with the same methods and the same results.

- {doc}`python`: classes, imported from the top-level package (`from ddma import ...`), plus
  the submodules {mod}`ddma.invariance`, {mod}`ddma.rl` and {mod}`ddma.plotting`.
- {doc}`matlab`: the `+ddma` package, functions on structs (`S = ddma.fit(...)`).

{doc}`../guides/parity` maps every Python name to its MATLAB counterpart.
